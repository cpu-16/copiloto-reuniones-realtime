# Imágenes del README

Sube aquí tus capturas y el video demo (con contenido **no confidencial**):

| Archivo | Para qué |
|---------|----------|
| `demo.mp4` (o pega la URL de user-attachments) | video demo con play/pausa, arriba en el README |
| `demo.gif` | alternativa al video (autoplay, sin controles) |
| `screenshot-ventana.png` | captura de la ventana nativa (sección "La ventana por dentro") |

Cómo añadir el **video con controles**: edita el README en GitHub (✏️) y **arrastra** el `.mp4`
dentro — GitHub genera una URL `https://github.com/user-attachments/assets/...` que se
reproduce con controles. (Ver el comentario en la sección *Demo* del README.)

> ⚠️ **Importante:** no subas capturas con transcripción real de reuniones de clientes
> (nombres, IPs, infraestructura, datos de negocio). Usa una demo con contenido genérico
> — por ejemplo, reproduce un video en español de un tema cualquiera mientras grabas.
